About this lab

Purpose

I use daily challenges to systematically build an AI-augmented design workflow — not to replace design thinking, but to understand exactly where AI creates leverage and where human judgment is irreplaceable. This page is the honest documentation of that process.

What you'll find here

Real prompts, real outputs, real critique. Each entry captures the challenge brief, the approach taken, key prompt strategies, a before/after where relevant, and a candid reflection on outcomes and surprises.

Why it matters

I'm deliberately moving toward climate tech, where complex data and expert users are the norm. The daily challenges feed directly into Terra — a consumer app I'm designing and building in parallel. AI fluency is a meaningful differentiator — this lab is how I build it intentionally, not accidentally.

Tools in rotation

Claude for reasoning, critique, and code generation. Claude Code in VS Code for building components and pages. Figma as the source of truth. Other tools introduced deliberately — only when a specific gap appears.

My approach

How each challenge works

01 —

Define the brief

One Daily UI prompt, one design problem. Write the brief before opening any tool. Vague inputs produce vague outputs — specificity is the skill.

02 —

Build with Claude Code

Build the component or page in Claude Code (VS Code). Ship working HTML/CSS first — code before canvas. Document the real prompts used, not polished ones.

03 —

Translate to Figma

Pull the built output into Figma. Refine, add variants, check accessibility, enforce design system rules. Figma validates; Claude Code accelerates.

04 —

Extract the insight

One honest takeaway: a prompt pattern worth keeping, a workflow adjustment, or where AI didn't help. Log it. That's the point of this page.

#001 May 2026
Workflow Claude Portfolio

Building my AI lab page from scratch with Claude

Challenge: design and build a portfolio sub-page that documents my AI workflow experiments — without opening Figma first. Starting point was a brief description of intent and a link to my existing portfolio. Goal was to ship a visually cohesive, production-ready page that matches my existing aesthetic while solving a real information architecture problem.

Tool used

Claude Sonnet

Challenge type

Page design & IA

Time to first draft

~15 minutes

→

Outcome: Claude fetched the live portfolio URL, extracted the visual language (dark bg, monospace accents, editorial typography), and generated a fully structured HTML page matching the aesthetic. Key insight: giving Claude a live URL produces dramatically better visual alignment than describing the style in words. The IA structure also came out cleanly on the first pass because the brief was specific about the content types needed.
